# Sistema visual · Threat Intelligence Operations

[← Início](../README.md)

## Conceito

Uma central de investigação com hierarquia editorial: títulos amplos, superfície escura, grade discreta e geometria de observação. O círculo segmentado representa investigação e validação; é um elemento autoral, não o logotipo oficial da Wazuh.

As quatro primeiras cores vêm do [guia de identidade Wazuh](https://wazuh.com/docs/Wazuh-logo-usage.pdf). As demais são extensões deste projeto. As cores das trilhas são convenções editoriais, não níveis de severidade.

## Regras de composição

- Arial/Helvetica como fontes portáveis dentro dos SVGs; tipografia nativa do GitHub no Markdown.
- Fundo próprio nos vetores para consistência nos temas claro e escuro.
- Rótulos textuais acompanham as cores; a cor nunca é a única forma de distinguir uma trilha.
- Banner principal em 1200 × 450; cartões em 1200 × 270; capas de trilha em 1200 × 180.
- SVGs sem scripts, fontes remotas, imagens externas ou animações obrigatórias.
- Preserve o título acessível e a descrição alternativa ao reutilizar os ativos.
- Use texto Markdown para todo conteúdo essencial; imagens complementam a navegação.
